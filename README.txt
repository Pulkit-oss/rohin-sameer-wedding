Rohin & Sameer Wedding Website

Open index.html in Chrome or another modern browser.

Features:
- Embedded original photo gallery (works offline after extraction).
- Guestbook/comments saved in the browser's local storage.
- Photo/video upload gallery using IndexedDB, stored locally in the same browser/device.
- Uploaded media remains available when the page is reopened in that same browser profile.
- Private celebration stream placeholder for adding a non-explicit wedding livestream link.

Important:
The comments and uploads are LOCAL to the browser/device. They are not automatically shared with other visitors. A real shared website needs a backend/cloud database and media storage (for example Firebase, Supabase, or another hosting backend).

The requested Suhagraat livestream has not been added. The stream area is intentionally limited to a non-explicit wedding celebration stream.
